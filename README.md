# Simple Rule-Based Chatbot (Python)
A simple console-based chatbot built using Python.
This project was created as part of my CodeAlpha Python Programming Internship.


---

🔹 Features

Responds to greetings, farewells, gratitude, and basic questions

Keyword-matching logic (no AI model)

Beginner-friendly Python implementation

Clean and readable code

Console-based interface



---

🔹 Technologies Used

Python (lists, functions, loops, conditions, string handling)



---

🔹 How It Works

The chatbot:

Detects keywords like hi, hello, bye, thanks

Gives fixed responses based on user input

Continues chatting until the user types bye, goodbye, or see you



---

🔹 How to Run the Project

1. Make sure Python is installed on your system


2. Download the Chatbot.py file


3. Open terminal/Command Prompt and run:



python Chatbot.py


---

🔹 Example Conversation

You : hi
Bot :  Hi there! How can I help you ?

You : what can you do?
Bot :  I can chat with you and answer simple questions. I'm still learning!

You : bye
Bot :  Goodbye! Have a great day!
